# Moj stack Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Korisnici beleže dodatne suplemente koje piju (pretraga kataloga od 100 stavki + „Drugo"), nedeljno potvrđuju stack, a admin vidi zbirni pregled.

**Architecture:** Jedna tabela `user_supplements` (migracija `0005`), katalog kao konstanta u kodu sa klijentskom pretragom bez dijakritika, SQL logika u `lib/supplements/store.ts` (tanke `createAction` akcije iznad nje, da `qa-sql` izvršava PRAVE funkcije), čista pravila (potvrda, pretraga, maskiranje malih grupa) u modulima bez `server-only` koje pokriva `qa-dates`. Admin agregat je jedan SQL u `lib/admin/stack.ts`.

**Tech Stack:** Next.js App Router + TypeScript, Drizzle + Neon Postgres, zod 4, Tailwind brand tokeni, shadcn/ui, sonner, lucide-react. Spec: `docs/superpowers/specs/2026-10-19-moj-stack-design.md`.

## Global Constraints

- Sav tekst u UI-ju na srpskom (latinica), neformalno (ti-forma) i **rodno neutralan** (nema „dodao/la", „si koristio").
- „Danas" je ISKLJUČIVO `belgradeToday()` iz `lib/dates.ts`; razlike datuma kroz `daysBetweenIso` / `addDaysIso`. Nikad `toISOString().slice(0,10)`.
- Sve server akcije kroz `createAction` (`lib/actions/safe-action.ts`); admin akcije sa `{ admin: true }`.
- Svaka nova `(app)` stranica počinje sa `const { profile } = await requireAppAccess()`.
- Boje samo kroz Tailwind brand tokene (`bg-lime`, `text-ink`, `text-slate-mid`, `text-slate-soft`, `bg-paper`, `bg-caution-soft`, `text-caution`); nikad hardkodovan hex.
- A11y: cilj za dodir ≥ 44px (`min-h-11` / `size-11`, ili `after:-inset-*`), tekst ≥ 12px (`text-xs`), ikona-dugme ima `aria-label`, fokus pun ink (globalno).
- Klijentski poziv server akcije MORA da hvata izuzetak (bez mreže akcija BACA) — vidi `components/protocol/dose-checkin.tsx`.
- `GROUP BY` nad izrazom nikad ne nosi bind parametar; konstante preko `sql.raw`.
- Svaki objekat koji migracija uvodi (tabela, indeks) ide u `EXPECTED_SCHEMA` (`lib/db/expected-schema.ts`).
- Testovi koji pišu idu u `inRollback` (BEGIN/ROLLBACK); namerni prekršaji ograničenja u `mustFailInSavepoint`.
- Nema saglasnosti u aplikaciji (odluka Vladimira), nema push/mejl podsetnika za potvrdu, nema dnevnog štikliranja.
- Pre svakog commita: `npm run lint`; posle zadataka koji diraju SQL: `qa:sql` nad pravom bazom (Task 0). Poslednji zadatak: `npm run qa` + `npm run build`.

- [ ] **Step 5: Napiši `search.ts`**

```ts
import { SUPPLEMENT_CATALOG, type CatalogItem, type SupplementCategory } from './catalog'

/**
 * Pretraga kataloga — čist modul, radi na klijentu nad statičnom listom.
 *
 * Normalizacija: mala slova, `đ` → `dj`, uklanjanje dijakritika (č ć š ž),
 * brisanje apostrofa, sve ostalo što nije [a-z0-9] postaje razmak.
 */
export function normalizeSearch(input: string): string {
  return input
    .toLowerCase()
    .replace(/đ/g, 'dj')
    .normalize('NFD')
    .replace(/[̀-ͯ]/g, '')
    .replace(/['’`]/g, '')
    .replace(/[^a-z0-9]+/g, ' ')
    .trim()
}

/** Ispod ove dužine upita podstring poklapanje je preširoko („mg" bi pogodilo pola kataloga). */
const MIN_SUBSTRING_LEN = 3

interface Indexed {
  item: CatalogItem
  label: string
  aliases: string[]
}

const INDEX: Indexed[] = SUPPLEMENT_CATALOG.map((item) => ({
  item,
  label: normalizeSearch(item.label),
  aliases: item.aliases.map(normalizeSearch),
}))

/** Upit poklapa početak neke reči (ili više reči zaredom). */
function wordStart(haystack: string, q: string): boolean {
  return ` ${haystack}`.includes(` ${q}`)
}

/** Manje je bolje: 0 = početak reči u nazivu … 3 = podstring u aliasu. */
function score(e: Indexed, q: string): number | null {
  if (wordStart(e.label, q)) return 0
  if (q.length >= MIN_SUBSTRING_LEN && e.label.includes(q)) return 1
  if (e.aliases.some((a) => wordStart(a, q))) return 2
  if (q.length >= MIN_SUBSTRING_LEN && e.aliases.some((a) => a.includes(q))) return 3
  return null
}

/**
 * Rezultati rangirani: početak reči u nazivu, podstring u nazivu, početak reči u
 * aliasu, podstring u aliasu; unutar ranga redosled kataloga. Prazan upit vraća
 * celu (opciono kategorijom filtriranu) listu.
 */
export function searchCatalog(query: string, category?: SupplementCategory): CatalogItem[] {
  const q = normalizeSearch(query)
  const pool = category ? INDEX.filter((e) => e.item.category === category) : INDEX
  if (q === '') return pool.map((e) => e.item)

  const scored: Array<{ item: CatalogItem; s: number; i: number }> = []
  pool.forEach((e, i) => {
    const s = score(e, q)
    if (s !== null) scored.push({ item: e.item, s, i })
  })
  scored.sort((a, b) => a.s - b.s || a.i - b.i)
  return scored.map((x) => x.item)
}

/**
 * Tačno poklapanje (posle normalizacije) sa nazivom ili aliasom — za „Drugo" koje je
 * zapravo kataloška stavka ("Magnezijum", "mg"). Čuva se pod ključem kataloga.
 */
export function matchCatalogExact(name: string): CatalogItem | undefined {
  const q = normalizeSearch(name)
  if (q === '') return undefined
  return INDEX.find((e) => e.label === q || e.aliases.includes(q))?.item
}
```

```ts
import { daysBetweenIso } from '@/lib/dates'

/** Posle ovoliko beogradskih dana bez potvrde kartica pita „da li je stack isti". */
export const CONFIRM_AFTER_DAYS = 7

/** Admin agregat broji kao „aktivan" samo unos potvrđen u poslednjih ovoliko dana. */
export const FRESH_WITHIN_DAYS = 30

/**
 * `oldestConfirmedOn` = najstariji `last_confirmed_on` među AKTIVNIM redovima korisnika
 * (`null` kad nema nijednog). Razlika ide kroz kalendarske dane (`daysBetweenIso`) —
 * ms-aritmetika drifta na DST-u.
 */
export function needsConfirmation(oldestConfirmedOn: string | null, today: string): boolean {
  if (oldestConfirmedOn === null) return false
  return daysBetweenIso(oldestConfirmedOn, today) >= CONFIRM_AFTER_DAYS
}
```

```ts
/** Grupe od 1–2 korisnika se ne prikazuju brojem (zaštita od identifikacije u maloj bazi). */
export const MIN_GROUP_SIZE = 3

/** `null` = „< 3". Nula je bezbedna i prikazuje se kao nula. */
export function maskSmallGroup(n: number): number | null {
  return n > 0 && n < MIN_GROUP_SIZE ? null : n
```

```ts
import 'server-only'

import { and, asc, eq, isNotNull, sql } from 'drizzle-orm'

import { ActionError } from '@/lib/actions/types'
import { db, userSupplements } from '@/lib/db'
import type { StackRow } from './types'
import type { TimeOfDay } from './time-of-day'

/**
 * Sav SQL „Mog stack-a" na jednom mestu — akcije su tanke, a `qa-sql` izvršava OVE funkcije.
 *
 * Granica broji samo AKTIVNE unose (uklonjen unos oslobađa mesto; ponovno aktiviranje
 * računa se kao dodavanje). Nije invarijanta (check-then-act): paralelan unos sme da
 * prekorači granicu za koji red, što je prihvatljivo — granica brani od zloupotrebe,
 * ne od greške u računu.
 */
export const MAX_SUPPLEMENTS_PER_USER = 60

export type SupplementTarget = { catalogKey: string } | { customName: string }

export async function listActiveSupplements(userId: string): Promise<StackRow[]> {
  return db
    .select({
      id: userSupplements.id,
      catalogKey: userSupplements.catalogKey,
      customName: userSupplements.customName,
      timeOfDay: userSupplements.timeOfDay,
      doseNote: userSupplements.doseNote,
    })
    .from(userSupplements)
    .where(and(eq(userSupplements.userId, userId), eq(userSupplements.active, true)))
    .orderBy(asc(userSupplements.createdAt), asc(userSupplements.id))
}

/**
 * Upis je JEDNA izjava. Isti suplement (kataloški ključ ili slobodan naziv, case-insensitive)
 * REAKTIVIRA postojeći red i prepisuje doba dana/napomenu — jedinstveni indeksi ne
 * dozvoljavaju drugi. `on conflict` mora da ponovi predikat odgovarajućeg indeksa.
 */
export async function addSupplement(
  userId: string,
  target: SupplementTarget,
  fields: { timeOfDay: TimeOfDay; doseNote?: string },
  today: string,
): Promise<{ id: number }> {
  const [count] = await db
    .select({ n: sql<number>`count(*)::int` })
    .from(userSupplements)
    .where(and(eq(userSupplements.userId, userId), eq(userSupplements.active, true)))
  if ((count?.n ?? 0) >= MAX_SUPPLEMENTS_PER_USER) {
    throw new ActionError(`Stack je pun (najviše ${MAX_SUPPLEMENTS_PER_USER} unosa).`)
  }

  const doseNote = fields.doseNote ?? null
  const result =
    'catalogKey' in target
      ? await db.execute<{ id: number }>(sql`
          insert into ${userSupplements} (user_id, catalog_key, time_of_day, dose_note, last_confirmed_on)
          values (${userId}, ${target.catalogKey}, ${fields.timeOfDay}, ${doseNote}, ${today})
          on conflict (user_id, catalog_key) where catalog_key is not null
          do update set active = true,
                        time_of_day = excluded.time_of_day,
                        dose_note = excluded.dose_note,
                        last_confirmed_on = excluded.last_confirmed_on
          returning id`)
      : await db.execute<{ id: number }>(sql`
          insert into ${userSupplements} (user_id, custom_name, time_of_day, dose_note, last_confirmed_on)
          values (${userId}, ${target.customName}, ${fields.timeOfDay}, ${doseNote}, ${today})
          on conflict (user_id, lower(custom_name)) where custom_name is not null
          do update set active = true,
                        custom_name = excluded.custom_name,
                        time_of_day = excluded.time_of_day,
                        dose_note = excluded.dose_note,
                        last_confirmed_on = excluded.last_confirmed_on
          returning id`)

  const row = result.rows[0]
  if (!row) throw new Error('addSupplement: upis nije vratio red')
  return { id: Number(row.id) }
}

/** `false` kad red ne postoji ili nije korisnikov (ili nema nijedne izmene). */
export async function updateSupplementRow(
  userId: string,
  id: number,
  patch: { timeOfDay?: TimeOfDay; doseNote?: string | null; active?: boolean },
  today: string,
): Promise<boolean> {
  const set: Partial<typeof userSupplements.$inferInsert> = {}
  if (patch.timeOfDay !== undefined) set.timeOfDay = patch.timeOfDay
  if (patch.doseNote !== undefined) set.doseNote = patch.doseNote
  if (patch.active !== undefined) set.active = patch.active
  if (Object.keys(set).length === 0) return false

  const rows = await db
    .update(userSupplements)
    .set(set)
    .where(and(eq(userSupplements.id, id), eq(userSupplements.userId, userId)))
    .returning({ id: userSupplements.id })
  if (rows.length === 0) return false

  // Korisnik koji je upravo uredio stack ne treba da dobije karticu „da li je isti".
  await confirmStack(userId, today)
  return true
}

/** „Isti je": potvrđuje sve aktivne redove danas. Vraća broj potvrđenih. */
export async function confirmStack(userId: string, today: string): Promise<number> {
  const rows = await db
    .update(userSupplements)
    .set({ lastConfirmedOn: today })
    .where(and(eq(userSupplements.userId, userId), eq(userSupplements.active, true)))
    .returning({ id: userSupplements.id })
  return rows.length
}

export async function clearStack(userId: string): Promise<number> {
  const rows = await db
    .delete(userSupplements)
    .where(eq(userSupplements.userId, userId))
    .returning({ id: userSupplements.id })
  return rows.length
}

/** Ulaz za `needsConfirmation`: broj aktivnih i najstariji datum potvrde među njima. */
export async function getStackSummary(
  userId: string,
): Promise<{ activeCount: number; oldestConfirmedOn: string | null }> {
  const [row] = await db
    .select({
      activeCount: sql<number>`count(*)::int`,
      // `::text` — pg adapter bi inače vratio Date, neon-http string.
      oldestConfirmedOn: sql<string | null>`min(${userSupplements.lastConfirmedOn})::text`,
    })
    .from(userSupplements)
    .where(and(eq(userSupplements.userId, userId), eq(userSupplements.active, true)))
  return { activeCount: row?.activeCount ?? 0, oldestConfirmedOn: row?.oldestConfirmedOn ?? null }
}

/**
 * Admin: spaja slobodan unos sa ključem kataloga (ili poništava spajanje sa `null`).
 * `name` je tačno ono što vrati `lower(custom_name)` u admin listi — NE lowercase-uje se u JS-u,
 * jer `lower()` u Postgres-u zavisi od locale-a baze i dve strane moraju da se slažu.
 */
export async function mergeCustomSupplement(name: string, intoKey: string | null): Promise<number> {
  const rows = await db
    .update(userSupplements)
    .set({ mergedIntoKey: intoKey })
    .where(
      and(
        isNotNull(userSupplements.customName),
        sql`lower(${userSupplements.customName}) = ${name}`,
      ),
    )
    .returning({ id: userSupplements.id })
  return rows.length
}
```

```ts
import 'server-only'

import { and, eq, sql } from 'drizzle-orm'

import { addDaysIso } from '@/lib/dates'
import { db, profiles, userSupplements } from '@/lib/db'
import { maskSmallGroup } from '@/lib/supplements/aggregate-rules'
import { getCatalogItem } from '@/lib/supplements/catalog'
import { FRESH_WITHIN_DAYS } from '@/lib/supplements/confirm-rules'

/** Dužina liste slobodnih unosa (admin ekran, ne izvoz). */
const LIST_LIMIT = 50

export interface StackAggregateRow {
  /** Ključ kataloga (ili sirov ključ koji je izbačen iz kataloga). */
  key: string
  label: string
  /** Korisnici sa aktivnim unosom potvrđenim u poslednjih `FRESH_WITHIN_DAYS`; `null` = „< 3". */
  freshUsers: number | null
  /** Aktivni, ali nepotvrđeni duže od toga; `null` = „< 3". */
  staleUsers: number | null
  /** Nemaskiran broj — za sortiranje i udeo na serveru, NE za prikaz. */
  rawFreshUsers: number
}

export interface CustomEntryRow {
  /** Tačno `lower(custom_name)` iz baze — ide nepromenjeno u `mergeCustomSupplement`. */
  name: string
  users: number
}

export interface StackReport {
  /** Onboardovani korisnici (imenilac za udeo). */
  onboarded: number
  /** Korisnici sa bar jednim svežim aktivnim unosom. */
  usersWithStack: number
  rows: StackAggregateRow[]
  custom: CustomEntryRow[]
}

/**
 * Zbirni pregled stack-a. Samo agregat — nijedan red ne nosi `user_id` ni mejl.
 * Efektivni ključ = kataloški ključ, inače ključ u koji je admin spojio slobodan unos,
 * inače `custom:<naziv>`. `custom:*` ključevi NISU u glavnoj tabeli (imaju svoju listu).
 *
 * `GROUP BY` ide nad kolonama CTE-a (`supp_key` je alias izračunat u `eff`), a datum granice
 * je bind parametar samo unutar agregata — nikad u `group by`.
 */
export async function getStackReport(today: string): Promise<StackReport> {
  const cutoff = addDaysIso(today, -FRESH_WITHIN_DAYS)

  const [aggregate, custom, onboardedRow, withStackRow] = await Promise.all([
    db.execute<{ supp_key: string; fresh_users: number; stale_users: number }>(sql`
      with eff as (
        select user_id, active, last_confirmed_on,
               coalesce(catalog_key, merged_into_key, 'custom:' || lower(custom_name)) as supp_key
        from ${userSupplements}
      ),
      per_user as (
        select user_id, supp_key,
               bool_or(active and last_confirmed_on >= ${cutoff}) as fresh,
               bool_or(active) as is_active
        from eff
        group by user_id, supp_key
      )
      select supp_key,
             (count(*) filter (where fresh))::int as fresh_users,
             (count(*) filter (where is_active and not fresh))::int as stale_users
      from per_user
      where supp_key not like 'custom:%'
      group by supp_key
      having count(*) filter (where is_active) > 0
      order by fresh_users desc, stale_users desc, supp_key
    `),
    db.execute<{ name: string; users: number }>(sql`
      select lower(custom_name) as name, count(distinct user_id)::int as users
      from ${userSupplements}
      where custom_name is not null and merged_into_key is null and active
      group by lower(custom_name)
      order by users desc, name
      limit ${LIST_LIMIT}
    `),
    db
      .select({ n: sql<number>`count(*)::int` })
      .from(profiles)
      .where(and(eq(profiles.role, 'user'), eq(profiles.onboardingCompleted, true))),
    db.execute<{ n: number }>(sql`
      select count(distinct user_id)::int as n
      from ${userSupplements}
      where active and last_confirmed_on >= ${cutoff}
    `),
  ])

  return {
    onboarded: onboardedRow[0]?.n ?? 0,
    usersWithStack: Number(withStackRow.rows[0]?.n ?? 0),
    rows: aggregate.rows.map((r) => ({
      key: r.supp_key,
      label: getCatalogItem(r.supp_key)?.label ?? r.supp_key,
      freshUsers: maskSmallGroup(Number(r.fresh_users)),
      staleUsers: maskSmallGroup(Number(r.stale_users)),
      rawFreshUsers: Number(r.fresh_users),
    })),
    custom: custom.rows.map((r) => ({ name: r.name, users: Number(r.users) })),
  }
}
```
